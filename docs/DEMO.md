# 시연 영상 대본 (2분, v0.7.3 기준)

2026-11-12 다시 씀. 에뮬레이터의 실제 화면으로 찍는다. 이 영상이 보여 줄 것은 하나다. 앱이 묻고, "응" 한 뒤, 차의 공조 값이 실제로 바뀌고 돌아온다.

## 화면 배치와 준비

- 왼쪽: Pleos Connect 에뮬레이터(앱 화면과 그 아래 차 공조 패널).
- 오른쪽 위: Virtual Console(브라우저 `http://127.0.0.1:8088`). Climate 의 Recirculation 값이 보이게 둔다.
- 오른쪽 아래: 터미널. `adb logcat -s Kkaeugi.Gleo Kkaeugi.Verify` 를 띄워 둔다.
- 고정 자막(영상 내내 아래 작은 글씨): "Virtual Console 은 차량 신호 시뮬레이터입니다. 앱은 Vehicle SDK 로만 차를 바꿉니다. 화면의 ppm 은 센서 값이 아닌 추정값입니다."

에뮬레이터에서 못 바꾸는 것과 대신 쓰는 것

| 못 바꾸는 것 | 대신 쓰는 것 | 영상 표시 |
|---|---|---|
| 좌석 점유, 안전띠(Virtual Console 에 조작이 없다. 기본값은 운전석 없음, 나머지 네 자리 있음으로 고정) | 개발자 영역의 직접 입력(정차 화면 → 개발자 → 데모 콘솔의 자리 칩 "가족 4명 자리", "혼자 자리") | 자막 "좌석은 에뮬레이터에서 바꿀 수 없어 개발자 영역에서 직접 넣었습니다" |
| 90분 앉아 있기 | 데모 콘솔의 "트립시간 +90분(걷기 쉼)" | 구석에 "시간을 앞당김" |
| 2분 환기 | 개발자 영역의 데모 속도(분을 초로) | 자막 "데모 속도: 2분을 20초로" |
| 바깥 미세먼지 값(인터넷이 안 될 때) | 정차 화면 설정 "바깥 미세먼지 참고"에서 등급을 직접 고름 | 자막 "등급을 직접 골랐습니다" |

좌석을 adb 한 줄로 넣는 명령(`--es what seats --es value "1,1,1,0,1"`. 차례는 운전석, 조수석, 뒷줄 왼쪽, 가운데, 오른쪽)이 빌드에 들어 있으면 자리 칩 대신 그 명령을 써도 된다. 그때는 터미널에 명령이 보이게 찍는다. 직접 넣은 값이 듣지 않으면 기본값 그대로(운전석까지 다섯 명) 찍고 자막의 사람 수를 화면에 맞춘다.

촬영 전 확인
- [ ] `adb uninstall ai.kkaeugi.app` 뒤 `adb install apk/안준영_숨_release.apk`. 위에 "Pleos 연결" 알약이 뜨는지 본다. "모의 모드"면 영상에 "모의 실행"이라고 적는다.
- [ ] 정차 화면 → 개발자: 데모 속도 켬, 증거 모드 켬. 나머지 실험 토글은 끈다.
- [ ] Virtual Console: Telltales 의 주차브레이크 경고등 끔, Systems 의 라이트 Off, Climate 의 Power 켬, Auto 끔, Fan speed 3 근처, Body 의 창문 넷 닫힘. 공조 전원이 꺼진 채 시작하면 앱이 전원을 켰다가 끄는 장면이 섞인다.
- [ ] 정차 화면 설정 "바깥 미세먼지 참고"를 켜고 등급을 "보통"으로 고른다. 호흡기 주의 자리에 사람이 타면 한 단계 나쁘게 봐서 "짧게 바꾸고 되돌리는" 질문이 나온다. 등급 값이 없으면 넷이 탔을 때 "바꿔 둘까요?"가 나와 원복 장면이 없다.
- [ ] 자리 칩으로 넣은 자리가 5초 뒤에도 좌석 지도에 남는지 본다(앱이 좌석 센서를 5초마다 다시 읽는다). 센서 값에 덮이면 그 사실을 적고 adb 좌석 명령이 든 빌드로 찍는다.
- [ ] 주행 홈 "다음 쉼터" 행에 쉼터 이름이 뜨는지 본다. 안 뜨면 데모 콘솔에서 "위치: 경부선 칠곡(모의 기본)"을 고른다.
- [ ] 화면에 이름, 이메일, 계정이 보이지 않는지 본다.

1:45 장면의 명령


Gleo 컷은 주행 중에 찍어 둔 것을 끼운다. 도착한 뒤에 보내면 답이 "아직 추정값이 없어요"로 나온다. 따로 찍은 컷이라는 것을 숨기지 않게 구석 타이머를 보여 준다.

## 장면마다 알아 둘 것

- 0:40 의 질문 끝부분("…만")은 그날 계산한 길이라 미리 적지 않았다. 데모 속도에서는 초로 읽는다. 찍은 문장 그대로 자막에 옮긴다.
- 1:00 의 원복은 에뮬레이터 실측 결과를 정리하는 중이다. `[실측 결과 기재 예정: 원복]` 고친 빌드로 다시 돌려 본 뒤에 찍는다. 원복이 화면에 잡히지 않으면 이 10초를 빼고, 자막에 "원복은 확인 중"이라고 적는다. 되는 것처럼 편집하지 않는다.
- 1:10 의 경유지 추가는 아직 실측 표에 없다. 찍기 전에 한 번 해 본다. 실패하면 증거 띠의 실패 줄을 그대로 보여 주고 자막을 "경유지 추가는 에뮬레이터에서 확인 중"으로 바꾼다.
- 음성 "응"은 Pleos STT 가 준비되고 마이크 권한이 있을 때만 받는다. 자막은 실제로 쓴 방법(터치 또는 음성)에 맞춘다.
- 차 값이 바뀌는 순간(0:50, 1:00, 1:20)에는 증거 띠가 같이 보이게 잡는다.
- 잘라 붙인 구간에는 구석 타이머를 띄운다.

## 예비 컷 (본편에 넣지 않고 따로 찍어 둔다)

- 혼자 출근: 데모 콘솔 "혼자 자리" → 기어 D, 내기순환 켬 → 약 20초 뒤 "차 안 공기가 탁해진 것 같아요(추정 2,000ppm). 20초만 바깥 공기로 바꿀까요?" → "응" → 원복. 자막 "혼자 타는 날은 약 20분에 한 번만 묻습니다."
- 차가 물러나는 장면(10초): Virtual Console 의 Climate 에서 Auto 를 켠다(앱이 읽는 자동 내기순환 값이 이것으로 켜지는지 먼저 본다) → 홈에 "차가 내외기를 자동 조절 중이에요", 제안이 나오지 않는다. 자막 "차가 스스로 조절하는 중이면 이 앱은 바꾸지 않습니다."

- 맡긴 뒤 예고: 설정 "2분 환기 맡기기" 켬 → "…바깥 공기로 바꿀게요. 싫으면 '아니'라고 하세요." → 5초 뒤 바뀜.

## 자막과 말에서 지킬 것

- ppm 에는 늘 "추정"을 붙인다.
- 쓰지 않는 말은 EVIDENCE.md 의 I-9, J-5 절에 있다. 자막 초안은 이 문서에 적어 두고 그 목록으로 검사한다.
- 터널을 안다고 읽히는 말, 내비가 앞에 있어도 동작한다는 말은 하지 않는다.
- 다른 출품작 이름은 말하지 않는다.
